#  ASCII Art Converter & Webcam Renderer

Python-инструмент для конвертации PNG-изображений и видеопотока веб-камеры в текстовый ASCII-арт. Проект включает низкоуровневый парсер PNG, интерфейс командной строки, режим реального времени для веб-камеры и графическое приложение на PyQt6.

---

##  Описание
Приложение декодирует PNG-файлы на уровне байтов (без использования `Pillow` или `OpenCV` для загрузки), применяет алгоритмы дефильтрации PNG, преобразует яркость пикселей в символы из настраиваемых наборов и выводит результат в консоль, текстовый файл или графическое окно. Отдельный модуль обеспечивает захват видеопотока с веб-камеры и рендеринг ASCII-кадров в реальном времени.

---

##  Возможности
-  **Парсинг PNG**: ручная распаковка IDAT, поддержка фильтров `0–4`, цветовых типов `0, 2, 3, 6`
-  **Гибкие наборы символов**: встроенные пресеты (`standard`, `detailed`, `blocks`) + загрузка из внешнего `.txt` файла
-  **Коррекция пропорций**: автоматический учёт соотношения сторон шрифта для точного отображения
- ️ **CLI-режим**: пакетная конвертация изображений с сохранением в файл или выводом в терминал
-  **Webcam-режим**: захват видео в реальном времени, зеркалирование, адаптивный ресайз окна
-  **GUI**: графический интерфейс на базе `PyQt6` (модуль `gui_app.py`)

##  Использование

###  Режим командной строки (CLI)
```bash
python -c "from ascii_app import ASCIIApp; ASCIIApp().run()" -i image.png -o result.txt -c detailed
```
**Доступные флаги:**
- `-i, --input` - Путь к входному PNG-файлу 
- `-o, --output` - Путь для сохранения `.txt` результата 
- `-c, --charset` - Набор символов: `standard` (по умолч.), `detailed`, `blocks`, `simple` или путь к файлу 
- `--webcam` - Запуск режима захвата веб-камеры 

###  Режим веб-камеры
```bash
python -c "from ascii_app import ASCIIApp; ASCIIApp().run()" --webcam
```
- Камера автоматически зеркалируется
- Окно масштабируется перетаскиванием углов
- Выход: `Esc` или закрытие окна

###  Графический интерфейс (GUI)
```bash
python main.py
```
*Требует наличия файла `gui_app.py` с классом `ASCIIAppGUI`.*

##  Описание модулей

| Файл | Назначение |
|------|------------|
| `main.py` | Инициализирует `QApplication`, применяет стиль `Fusion`, запускает главное окно |
| `image_processor.py` | Содержит `ImageProcessor` и `Image`. Распаковывает PNG-чанки (`IHDR`, `PLTE`, `IDAT`, `IEND`), применяет фильтры (None, Sub, Up, Average, Paeth), конвертирует цвет в оттенки серого |
| `ASCII_converter.py` | Класс `ASCIIConverter`. Загружает пресеты/файлы символов, маппит яркость `0–255` на индекс набора, собирает итоговую строку |
| `io_handler.py` | Класс `IOHandler`. Настраивает `argparse`, выводит результат в `stdout` или сохраняет в файл с кодировкой `utf-8` |
| `webcam_ascii.py` | Класс `WebcamASCII`. Захватывает кадры, ресайзит с учётом `0.55` (коррекция шрифта), отрисовывает символы через `cv2.putText`, масштабирует окно динамически |
| `gui_app.py` | Предполагаемый модуль с `ASCIIAppGUI(QMainWindow)` для визуального интерфейса |
